# Czysto u Marii — React + TypeScript + Vite

Редагований проєкт лендингу послуг прибирання. Збережено дизайн, польські
тексти, контакти, зображення й адаптивність попередньої версії.
Це незалежна копія для твого комп'ютера; вона не змінює опублікований сайт.

## 1. Запуск у Windows / VS Code

Потрібні Node.js версії 22.12 або новішої та npm. Можна використовувати Node.js 24.
Перевір у терміналі `node -v` і `npm -v`. Якщо Node.js ще немає, встанови його
з https://nodejs.org/ і перезапусти VS Code.

1. Розпакуй ZIP повністю.
2. У VS Code вибери File → Open Folder → папку `czysto-u-marii` (з package.json).
3. Відкрий Terminal → New Terminal.
4. Виконай команди по черзі:

```bash
npm install
npm run dev
```

Відкрий адресу, яку покаже Vite (зазвичай http://localhost:5173).
Зміни файл, збережи через Ctrl+S — сторінка оновиться автоматично.
Для зупинки сервера натисни Ctrl+C у терміналі.

Якщо PowerShell блокує `npm.ps1`, вибери термінал Command Prompt
або використовуй `npm.cmd install` та `npm.cmd run dev`.
Не потрібно змінювати політику безпеки Windows.

Не запускай React-версію подвійним натисканням index.html чи через Live Server:
її запускає Vite командою npm run dev.

## 3. Як редагувати

- Контакти: `src/data/site.ts`, об'єкт `contact`.
- Послуги: у тому самому файлі масив `services`. Картки та варіанти форми
  оновлюються з одного джерела. `id` кожної послуги має бути унікальним.
- FAQ: масив `faqs`.
- Заголовки, текст про себе: відповідні компоненти в `src/components`.
- Кольори: змінні `--paper`, `--ink`, `--green`, `--muted`, `--line`, `--sage`
  у `:root` на початку `src/styles/globals.css`.
- Адаптивність: блоки `@media` наприкінці CSS; їх перенесено з першої версії.
- Фото: заміни `public/images/hero.webp`. Якщо назва чи формат інші,
  онови шлях у `Hero.tsx` і опис `alt`.
- Заголовок у вкладці браузера й опис: `index.html`.

Шрифти DM Sans і Playfair Display завантажуються з Google Fonts і потребують інтернету.
Без інтернету використовуються запасні шрифти.

## 4. Команди

```bash
npm run dev        # Розробка з автоматичним оновленням
npm run typecheck  # Перевірка TypeScript
npm run build      # Перевірка типів і production-збірка з готовим HTML
npm run preview    # Локальний перегляд після npm run build
```

На хостинг завантажується папка `dist`, створена командою `npm run build`.
Для повторюваного встановлення за lock-файлом можна використовувати `npm ci`.

## 5. Форма й дані

Форма використовує React useState, useRef і типізовані події. Вибір картки
оновлює select через стан App. Обов'язкові поля перевіряються браузером.
Після заповнення відкривається поштова програма з підготовленим листом.
Клієнт підтверджує надсилання сам. Серверного надсилання та збереження заявок немає.
Якщо пошта не налаштована, можна скопіювати текст або зателефонувати.
При недоступному Clipboard API текст виділяється для ручного копіювання.

## 6. HTML і пошук

Production-збірка попередньо рендерить React у HTML: тексти сторінки доступні
ще до запуску JavaScript. React потім підключає інтерактивність через hydration.
Окремий Node.js-сервер на хостингу для цього не потрібний.
Код, що використовує window/navigator, розміщено в обробниках подій, щоб він
не виконувався під час генерування HTML. Дотримуйся цього при додаванні функцій.
Це технічна основа для SEO, але не гарантія позицій. Домен, Search Console,
Google Business Profile і публічний доступ налаштовуються окремо.
